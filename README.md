# MIR4 Idle — referências para Google Stitch

Este repositório reúne o briefing e as referências para criar uma nova identidade visual para as interfaces do MIR4 Idle. Leia [o briefing completo](PRIMEIRO_LEIA_BRIEFING.md) e [.stitch/DESIGN.md](.stitch/DESIGN.md).

As telas existentes mostram funcionalidades e conteúdo, não uma direção visual aprovada. O visual principal dos mapas deve ser preservado. Os chefes gerados são conceitos; sua identidade canônica não foi verificada. O repositório contém imagens de telas com identificadores de contas e personagens de teste.
